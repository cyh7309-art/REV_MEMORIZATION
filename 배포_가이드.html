DEPLOYMENT GUIDE · GITHUB PAGES

계시록 암송 트레이너를
다른 사람들도 쓸 수 있게 배포하기

GitHub Desktop만 사용하는 방법이에요. 명령어를 직접 입력할 필요는 없고, 화면의 버튼을 순서대로 누르기만 하면 됩니다. 전체 과정은 15~20분 정도 걸려요.

지금 → https://[아이디].github.io/[저장소이름]/ → 누구나 이 주소로 접속해서 바로 사용

시작 전에

  • 준비된 것 — 폴더 안에 git 저장소를 이미 만들어 두었습니다. 첫 커밋(계시록 암송 트레이너 초기 배포 준비)까지 완료된 상태예요. 아래에서 바로 GitHub Desktop에 연결하면 됩니다.
  • 필요한 것 1 — GitHub 계정 (없다면 2분이면 만듭니다, 무료)
  • 필요한 것 2 — GitHub Desktop 앱 (무료, Mac용)
  • 알아둘 점 — 저장소는 공개(Public)로 만드는 걸 권장해요. 성경 본문과 앱 코드에는 민감한 정보가 없고, 무료 계정에서 GitHub Pages를 가장 안정적으로 쓸 수 있는 방식이에요.
Step 1 – 4 · 저장소 게시
1

GitHub 계정 만들기 (이미 있다면 건너뛰기)

github.com 에 접속해서 우측 상단 Sign up으로 이메일과 비밀번호만 입력하면 됩니다. 아이디(username)는 나중에 주소에 그대로 들어가니 기억하기 쉬운 걸로 정해주세요. 예: hoze7branch

2

GitHub Desktop 설치 후 로그인

desktop.github.com 에서 Mac용을 내려받아 설치합니다. 실행 후 Sign in to GitHub.com을 눌러 1번에서 만든 계정으로 로그인하세요.

3

이 폴더를 저장소로 추가하기

GitHub Desktop 메뉴에서 File → Add Local Repository를 선택하고, 계시록암송웹개발 폴더(바탕화면에 있는 그 폴더)를 지정합니다.

이미 git 저장소로 준비되어 있어서 바로 인식됩니다 — "create a repository" 안내가 뜨면 그건 무시하고, 목록에 저장소가 바로 나타나는지 확인하세요.

4

Publish repository 클릭

왼쪽 상단의 Publish repository 버튼을 누릅니다. 이름을 확인하고(예: revelation-memory-trainer), Keep this code private 체크를 해제한 뒤 Publish Repository를 클릭하세요.

주의

"Keep this code private" 체크를 해제해야 무료 계정에서 GitHub Pages 주소가 바로 열립니다. 체크된 채로 두면 5번 단계에서 Pages 설정이 보이지 않을 수 있어요.

Step 5 · Pages 켜기
5

GitHub 웹사이트에서 Pages 활성화

GitHub Desktop에서 Repository → View on GitHub을 누르면 브라우저로 저장소 페이지가 열립니다. 상단 Settings 탭 → 왼쪽 메뉴 Pages로 이동하세요.

Build and deployment 항목에서 Source를 Deploy from a branch로, Branch를 main / / (root)로 지정하고 Save를 누릅니다.

TIP

저장 후 1~3분 정도 기다리면 같은 화면 상단에 Your site is live at ... 라는 문구와 함께 최종 주소가 표시됩니다. 그 주소를 학생·성도들에게 공유하면 됩니다.

배포 이후

나중에 내용을 수정했다면

GitHub Desktop을 다시 열고, 왼쪽에 바뀐 파일 목록이 보이면 하단에 커밋 메시지(예: 문항 데이터 수정)를 적고 Commit to main → Push origin 순서로 누르면 됩니다. 1~2분 뒤 같은 주소에 자동 반영돼요.

중요

오프라인 캐시(PWA) 때문에 이미 접속했던 사람 화면에는 옛 버전이 남아있을 수 있어요. 파일을 고칠 때마다 sw.js 맨 위의 CACHE_VERSION 값을 rev-memory-v2 처럼 한 칸씩 올려서 커밋하면, 사용자 브라우저가 새 버전을 자동으로 받아갑니다.

여러 학습자의 기록을 취합하고 싶다면

이 앱의 학습 기록은 각자의 기기(브라우저)에만 저장돼요. 서버에 모이는 구조가 아니라서, 부서 전체 통계를 보려면 아래 방식이 필요합니다.

  • 학습자가 앱의 설정 → 백업 내보내기에서 JSON 파일을 저장
  • 그 파일들을 서무님께 전달 (카톡·이메일 등)
  • 앱의 학습 기록 → 리포트 화면에서 여러 JSON을 한 번에 불러오면, 인원별·범위별 평균과 자주 틀리는 절이 자동으로 CSV로 정리됩니다
문제해결
증상해결
Publish 버튼이 안 보이거나 회색이다 GitHub Desktop 좌측 상단에 계정이 로그인되어 있는지 확인하세요 (File → Options → Accounts).
Pages 메뉴에서 저장할 브랜치가 없다고 나온다 4번 단계에서 Publish가 아직 안 된 상태예요. GitHub Desktop에서 Publish repository를 먼저 완료하세요.
주소에 접속했는데 흰 화면만 나온다 저장 직후에는 1~3분 정도 배포 시간이 걸립니다. 잠시 후 새로고침(Shift+새로고침으로 캐시 무시)해보세요.
"홈 화면에 추가"(PWA 설치)가 안 보인다 GitHub Pages 주소(https://...)로 접속했는지 확인하세요. 로컬 파일(file://)로 열면 설치 기능이 동작하지 않습니다.
음성 입력 버튼이 비활성화되어 있다 역시 https 주소에서만 동작합니다. GitHub Pages로 배포한 뒤에는 정상적으로 켜집니다.
